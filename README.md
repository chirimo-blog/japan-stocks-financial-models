## What's Included in Each Model
- **Historical Financial Statements**: 3–5 years of quarterly P&L, B/S, and Cash Flow.
- **KPI Dashboards**: Cohort metrics, unit economics, segment breakdowns.
- **Valuation Benchmarks**: EV/EBITDA, P/E, P/S historical multiple tracking.
- **Format**: Clean, non-macro `.xlsx` file (compatible with Excel & Google Sheets).
